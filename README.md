# 拾句在线内容库

为「拾句」App 提供可缓存的古典诗句与配套解析。

- 内容版本：2
- 诗句及配套解析：124 条
- 格式版本：1
- 发布状态：开发预览；完成来源辅助开发复核，人工编辑终审待完成（pending）。本次部署用于验证在线内容更新，不表示已经人工签核。

## 内容入口

App 读取同目录的 `manifest.json`，根据版本号下载清单指定的不可变 JSON 内容包，并验证 SHA-256、原文资料和解析匹配。断网时继续使用本地缓存。

## 内容来源

古代作者原文属于公有领域；采用简体字与现代标点。每条保留作者、作品、校对参考、固定来源修订链接和使用依据，原文参考主要为维基文库。译意、赏析与注释为拾句项目整理的原创开发稿，尚待人工编辑终审，不把源站现代译注作为应用解析发布。

维基文库的现代编辑资料受源站适用许可约束，详见 https://zh.wikisource.org/wiki/Wikisource:著作权方针 。逐条原文修订链接随内容包保留。本仓库未给第三方资料另行授予许可，也不对古典原文主张独占权利。

## 更新方式

1. 编辑完整内容库并校对原文及配套解析，保留已有稳定 ID。
2. 使用拾句项目的 ShijuContentPublisher 导出更高版本；按真实状态记录人工终审，不将开发复核当成人工终审。
3. 先上传内容包，等 Pages 部署完成；再更新 manifest.json 并等待第二次部署。保留旧内容包。
4. 清单地址保持不变，App 在下次自动检查或设置中手动检查后获得更新。

这里只托管内容文件；不包含 App 源代码、收藏、浏览记录或用户反馈。
